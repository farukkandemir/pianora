# Built-in catalogue

Public-domain piano scores bundled with the app and listed in
`src/catalog/catalog.ts`. All files come from the MuseTrainer public-domain
MusicXML library (https://github.com/musetrainer/library), downloaded
2026-09-11, except `gymnopedie-1.mxl`, which is the copy in `../../../scores/`.

The compositions are public domain. The "(easy)" files are simplified
arrangements by MuseScore users that the MuseTrainer library republishes as
public domain; if that provenance ever matters (e.g. App Store legal review),
those are the ones to re-check or replace with original editions.
